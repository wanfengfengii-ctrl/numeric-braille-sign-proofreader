# 电梯厅数字房间牌 · 六点盲文校样台

纯前端校样台：把明眼稿房间牌代码编码为六点盲文目标单元带，与实物抄录单元逐点比较，避免“看似逐位对应、实际漏加数字标志”的错牌流出。

## 编码规则

- 点位编号：左列自上而下为 1、2、3，右列为 4、5、6。
- 数字标志固定为 `3456`；数字 1–0 依次为 `1、12、14、145、15、124、1245、125、24、245`。
- 连字符 `-` 为 `36`，斜杠 `/` 为 `34`，空格为空单元。
- 每个连续数字段前必须且只能出现一个数字标志；任一分隔符都会结束数字状态。
- 输入仅接受数字 0–9、半角连字符、斜杠和单个空格；分隔符不得位于首尾或连续出现。

## 校样流程

1. 左侧输入房间牌代码，实时得到目标单元带。
2. 右侧“添加单元”后逐点抄录：点击圆点，或聚焦单元后按 `1`–`6` 切换点位（`←`/`→` 移动、`Enter` 插入、`Backspace` 删除）。
3. 右侧实时反向解读出可解读代码；遇到缺少数字标志、数字标志重复或未知点阵时不猜测字符，并清除旧的一致结果。
4. 比较以点集合为准：单元数量或任一点不同都判为不一致，并聚焦首个差异单元；全部一致时显示“房间牌一致 ✓ 可以送厂”。

## 技术栈

TypeScript + React + Vite；编码器由 Vitest 锁定全部映射与数字状态；Playwright 做端到端验收。

## 本地运行

```bash
npm ci
npm run dev        # http://localhost:3000
npm run test:unit  # Vitest
npm run test:e2e   # Playwright（自动拉起 dev server）
npm run verify     # 单元 + 端到端一次性验收
```

## Docker

```bash
WEB_PORT=8080 docker compose up web   # 宿主端口由 WEB_PORT 覆盖，默认 3000
docker compose run --rm verify        # 一次性验收服务：Vitest + Playwright，跑完即退出
```
